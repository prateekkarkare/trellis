# Example Domain: `writing`

This is a fully-populated worked example. **It is illustrative only — delete this folder before going live.**

It shows what `mentors/writing/` looks like after ~6 weeks of real use:
- 4 completed session pages
- a populated `done_topics.md` catalog
- a current_focus.md mid-phase
- a curriculum.md that's been adapted twice
- an intel.md with external sources
- one phase archive

Use it to:
1. See the file shapes when populated (vs. the empty templates in `templates/domain/`).
2. Understand how the mentor compresses session → log → done_topics → focus over weeks.
3. Sanity-check your own setup — your files should feel similar after a month.

## How to delete

```bash
rm -rf examples/example_domain
```

## How to fork-and-edit

If `writing` resonates and you want to start your own writing domain from this populated state:

```bash
cp -r examples/example_domain ../my-notebook/mentors/writing
# Then edit out the example user's details and replace with your own context.
```

But normally you'd want a clean start — use `./scripts/add-domain.sh writing` instead.
