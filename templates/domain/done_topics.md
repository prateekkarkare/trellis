## Conventions

- **Status**: ✅ done · ⚠️ partial · ❌ skipped · 🔁 repeat (flag if the same topic was reassigned by mistake — feeds future DRIFT_CHECK)
- **Artifact**: notebook filename, deliverable path, or "—"
- **Notes**: one sentence max. Detail belongs in `sessions/<date>.md` or `log.md`.
- **Date**: use the session date. Approximate ("May ~6") only if the exact date is unrecoverable.

## How the mentor updates this file (JOURNAL, end of every domain session)

1. Append a row for the topic worked on.
2. Update the *Last updated* line at the top.
3. Commit via `scripts/sync.sh (optional)` (auto-called by SYNC protocol).

## How the mentor reads this file (PREPARE, start of every domain session)

1. Read the entire file (small by design — should fit easily in any context).
2. Build mental set of completed topic names.
3. Before recommending any topic, check this set. If present, do not reassign without explicit user direction.
